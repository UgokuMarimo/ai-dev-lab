# 試験運用期間中の設定最適化 & config.py 変更レポート

今年いっぱい（〜2027年1月）を試験運用期間と位置づけている中で、**「試験運用の途中で購入条件を変更すべきか否か」の客観的アドバイス**、および **`config.py` の最適化変更内容** を報告します。

---

## ⚖️ 1. 「途中で条件を変更しても良いか？」に対する結論と理由

### 結論: **【今すぐ設定を変更することを強く推奨します】**

### 理由:
1. **AIモデル本体の変更ではなく「ベティングフィルター（馬券購入条件）」の最適化であるため**:
   - 機械学習モデルのアルゴリズムや特徴量を途中で変えると過去の精度比較が崩れますが、今回は「AIが弾き出した予測勝率・期待値のうち、どのラインから馬券を購入するか」という**購入条件の最適化**です。
2. **バックテストにより、旧ルールのボトルネックが明確に解明されたため**:
   - 全1,075レースの実証データから、`1.3 <= EV < 1.8` のゾーンは「市場で適正評価されているオッズ10〜15倍の馬」が多く、購入しても回収率を低下（89.44%）させる原因になっていたことが判明しました。
   - マイナスになることが分かっている条件で貴重な資金と残り半年の試験運用期間を消化するよりも、バックテストで最高パフォーマンスを出した条件でフォワードテスト（実データ検証）を行う方が圧倒的に有益です。
3. **試験運用の真の目的**:
   - 試験運用の目的は「実運用で勝利できる最適ルールをリアルタイムデータで検証・確認すること」です。データに基づき最高条件（`EV >= 1.8`）へアップデートし、残りの8月〜1月（約500〜700レース）で**「本当にリアルタイム運用で回収率100%超えを維持できるか」**を確認するのが最も理想的な試験運用となります。

## ⚙️ 2. `config.py` の変更内容

[config.py](file:///c:/keibaAI/src/config.py#L332-L337) の期待値設定を以下のように更新いたしました。

```python
# --- 予測・馬券戦略設定 ---
TARGET_EV = 1.8         # ターゲット期待値 (最適化済み: 1.3 -> 1.8)
TARGET_EV_5MIN = 1.6     # 5分前足切り期待値しきい値 (最適化済み: 1.2 -> 1.6)
TARGET_EV_VOTE = 1.8     # 投票確定期待値しきい値 (最適化済み: 1.3 -> 1.8)
MIN_WIN_PROB = 0.10     # 最低勝率の閾値 (変更なし: 10%)
```

### 【確定した新・実運用ルール】:
- **AI予測勝率**: `10% 以上` (`MIN_WIN_PROB = 0.10`)
- **単勝オッズ**: `2.0倍 〜 30.0倍` (`AUTO_VOTING_MIN_ODDS = 2.0`, `AUTO_VOTING_MAX_ODDS = 30.0`)
- **期待値 (EV)**: **`1.8 以上`** (`TARGET_EV_VOTE = 1.8`) ★変更点★
- **購入頭数**: レース内最高EVの1頭のみ（単勝1点100円）
